# UI 작업 요약 — 2026-07-27

- Overview와 업무 탭이 같은 위험·제출물 데이터를 쓰도록 통합해 화면별 건수 불일치를 없앴다.
- 실격·감점뿐 아니라 위약금과 계약상 불이익도 추출해 실제 참여 판단에 필요한 위험 범위를 넓혔다.
- 위험 상태를 미확인·위험 있음·문제없음으로 저장해 `0건`이 분석 전인지 실제 결과인지 구분했다.
- 제출물 검색어를 다중화하고 빈 결과 캐시를 막아 착수서류·보고서 누락과 일시적 `0건` 고정을 줄였다.
- 입찰 제출서류와 계약 후 사업 산출물을 개별 항목·구역으로 분리해 준비 시점을 명확히 했다.
- Overview에 탭별 핵심 요약을 추가하고 목차·파일 목록을 접이식 탭으로 바꿔 작업 공간을 넓혔다.
- 파일 목록은 이름 검색과 날짜순·이름순 정렬만 남겨 불필요한 상태·난이도 필터를 제거했다.
- Evidence 패널 폭 조절·저장과 원문 중심 표시를 적용하고, Playwright를 PR·main CI에 연결해 근거 확인과 회귀 방지를 강화했다.
