아래는 RFP Action Copilot의 목표 UI 화면 설계다.
현재 구현된 코드와 비교해서 일치 여부를 체크해줘.

---

## 목표 UI 구조

### 전체 페이지 구성
- Page 1: RFP List (/rfp-list)
- Page 2: RFP Workspace (/workspace/:document_id)
  - Tab 1: Overview
  - Tab 2: Go / No-Go
  - Tab 3: 실행 준비
  - Tab 4: 요구사항
  - Tab 5: AI 질문
- Page 3: Evaluation (/internal/evaluation) — 내부 운영팀 전용, 네비게이션 미노출

---

## 디자인 기준

- 배경: 흰색(#ffffff) 카드 + 연회색(#f5f6f8) 페이지 배경
- 텍스트: #111827 (primary) / #374151 (secondary) / #6b7280 (muted)
- 상태바(statusbar): 네이비(#1e3a5f) 배경, 위험 수치는 빨강(#fca5a5)
- 실격 조건: 빨간 왼쪽 테두리 + 연빨강 배경 (#fef2f2)
- 감점 조건: 주황 왼쪽 테두리 + 연주황 배경 (#fffbeb)
- Evidence score < 0.7: ⚠️ 배지 표시
- 어두운 배경, 그라데이션, 그림자 효과 사용 금지

## 체크 항목

아래 항목을 하나씩 확인하고 결과를 표로 정리해줘.

### Page 1: RFP List
- [ ] 페이지 배경이 연회색(#f5f6f8)인가
- [ ] 카드에 D-Day 숫자가 크게 표시되는가
- [ ] D-7 이내는 빨강, D-14 이상은 파랑으로 구분되는가
- [ ] 실격 건수 배지가 빨간 계열인가
- [ ] 제출물 완료율 진행바가 있는가
- [ ] 업로드 카드(dashed border)가 있는가
- [ ] 검색, 마감순 정렬, 상태 필터가 있는가

### Page 2: RFP Workspace — 공통
- [ ] 3열 레이아웃인가 (좌: 문서 목록 / 중: 탭 / 우: 근거 패널)
- [ ] 상단 상태바가 네이비 배경으로 고정되어 있는가
- [ ] 상태바에 제출 D-Day / 질의 D-Day / 실격 건수 / 감점 건수 / 제출물 진행 표시되는가
- [ ] 탭이 5개 존재하는가 (Overview / Go No-Go / 실행 준비 / 요구사항 / AI 질문)
- [ ] 근거 패널이 우측에 sticky로 고정되는가
- [ ] 근거 패널에 문서명 / 페이지 번호 / 원문 인용 / 신뢰도 점수가 표시되는가
- [ ] 항목 클릭 시 근거 패널이 업데이트되는가

### Tab 1: Overview
- [ ] KPI 카드 6개가 있는가 (제출 마감 / 질의 마감 / 자격 충족 / 실격 위험 / 감점 위험 / 제출물 완료율)
- [ ] KPI 카드 상단에 색상 테두리로 심각도를 표시하는가
- [ ] 지금 할 일 목록이 있는가 (우선순위 점 색상 구분)
- [ ] 주요 일정 타임라인이 있는가

### Tab 2: Go / No-Go
- [ ] 자격 항목마다 ✅ / ❌ / ❓ 체크 버튼이 있는가
- [ ] 체크 상태가 새로고침 후에도 유지되는가 (user_state.json 저장)
- [ ] Evidence score < 0.7 항목에 ⚠️ 낮은 신뢰도 배지가 있는가
- [ ] 실격 조건이 빨간 카드로 표시되는가
- [ ] 감점 조건이 주황 카드로 표시되는가

### Tab 5: AI 질문
- [ ] 추천 질문 버튼이 있는가
- [ ] 추천 질문이 현재 activeTab 기준으로 달라지는가
- [ ] 답변이 스트리밍(타이핑 효과)으로 표시되는가
- [ ] 답변 아래에 근거 출처 칩(문서명 · 페이지 · 점수)이 표시되는가
- [ ] 스트림 오류 시 에러 메시지와 재시도 버튼이 표시되는가
- [ ] 채팅 히스토리가 최근 6턴으로 슬라이싱되어 전송되는가

### Phase 0 Mock 동작 (VITE_USE_MOCK=true 환경)
- [ ] VITE_USE_MOCK=true 시 src/mocks/*.json 데이터로 렌더링되는가
- [ ] VITE_USE_MOCK=false 시 FastAPI API를 호출하는가
- [ ] 두 모드 전환이 환경변수 하나로 되는가
