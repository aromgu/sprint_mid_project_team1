## 3. Retriever 비교 결과

95개 답변 가능 문항을 해당 문서 범위 안에서 평가했다.

| Retriever | Fact Coverage@5 | Fact Coverage@10 | Section Recall@5 | MRR@10 | 평균 지연 |
|---|---:|---:|---:|---:|---:|
| BM25 | 83.68% | 88.25% | 74.56% | 0.874 | 9.99ms |
| Dense | 58.25% | 70.26% | 54.74% | 0.688 | 107.72ms |
| Hybrid | 70.61% | 88.60% | 70.18% | 0.791 | 99.49ms |

### 판단

- 현재 한국어 RFP 데이터에서는 BM25가 가장 빠르고 전반적으로 우수했다.
- Hybrid는 Fact Coverage@10만 BM25보다 소폭 높았다.
- Dense 단독 검색은 정확도와 속도 모두 불리했다.
- 구어체 질문은 여전히 가장 취약했다.

## 4. 104문항 답변 생성 및 RAGAS 평가

### 답변 평가

| 지표 | 결과 |
|---|---:|
| Answerability Accuracy | 88.46% |
| Required Fact Coverage | 51.14% |
| Numeric Recall | 58.24% |
| Numeric Precision | 56.76% |
| Ground-truth Token Coverage | 32.49% |
| 추정 답변 생성 비용 | 약 $0.0475 |

### RAGAS 평가

| 지표 | 결과 |
|---|---:|
| Faithfulness | 0.605 |
| Answer Relevancy | 0.308 |

### 해석

- 검색 성능에 비해 최종 답변의 완전성이 낮았다.
- 복합 질문에서 일부 항목만 답하고 나머지를 누락하는 문제가 컸다.
- 문서에 근거가 있는데도 답변을 거절하는 사례가 확인됐다.
- 근거 충실도는 중간 수준이지만 질문 요구에 직접 답하는 정도는 낮았다.

## 5. 복합 질문 검색 개선

### 구현 사항

- 질문에서 요구 항목 분리
- 예산과 유지보수 기간 등을 별도 검색
- RFP 기술용어와 유사 표현 확장

```text
유지보수 → 하자보수, 유지관리, 안정화 지원
예산 → 사업비, 소요예산, 추정가격, 계약금액
```

- 각 하위 질문별 BM25 검색
- 검색 top-k를 5에서 10으로 확대
- 하위 검색 결과를 Chunk ID 기준으로 병합
- 요구사항 ID, 금액, 기간이 포함된 청크에 가중치 적용
- 확인된 항목은 답하고 찾지 못한 항목만 `미확인` 처리
- 답변을 항목별 줄바꿈으로 출력

### 검증

```text
14 passed, 1 warning
```

### 발견된 한계

현재 질문에 예산이나 유지보수 용어가 있으면 매칭된 항목만 검색 계획에 남고 다른 요구사항이 누락될 수 있다.

```text
총 사업비 + 공동수급 제한
→ 예산만 검색

하자보수 기간 + 요청 후 처리 방식
→ 하자보수 기간만 검색
```

다음 개선에서는 용어 그룹에 매칭되지 않은 나머지 요구 항목도 별도 하위 질문으로 보존해야 한다.

## 10. OpenAI/Gemini 5문항 비교

동일한 농수산 문서 5문항을 비교했다.

| 지표 | ChatGPT nano | Gemini 3.5 Flash |
|---|---:|---:|
| 답변 처리 | 4/5 | 5/5 |
| 인용 포함 | 4/5 | 5/5 |
| 필수 사실 충족 | 약 3/14 | 약 9/14 |
| 평균 생성시간 | 2.10초 | 13.42초 |
| 입력 토큰 | 39,673 | 37,872 |
| 출력 토큰 | 573 | 532 |

### 판단

- Gemini는 복합 질문과 숫자·기한 추출에서 더 정확했다.
- ChatGPT nano는 약 6배 빠르고 비용이 낮았다.
- Gemini 비용이 0으로 기록된 것은 무료여서가 아니라 가격 설정이 없기 때문이다.
- 품질 우선이면 Gemini, 실시간 응답성과 비용 우선이면 ChatGPT nano가 유리하다.
- 5문항 표본이므로 질문 분해 문제를 수정한 후 더 큰 표본으로 재평가해야 한다.
