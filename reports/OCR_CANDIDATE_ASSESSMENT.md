# OCR 후보 페이지 판정 보고서

## 1. 판정 기준

- `필수`: 검색 또는 답변 근거가 될 실질적인 텍스트가 이미지에 포함돼 OCR/멀티모달 추출이 필요함
- `권장`: 검색 핵심 근거는 아니지만 구조나 현황 정보의 활용 가능성이 있음
- `불필요`: 빈 페이지 또는 기입 전 서식으로 검색할 실질 내용이 없음

PDF 페이지 번호는 파일의 물리적 페이지 순서를 기준으로 한다. 문서에 인쇄된 페이지 번호와 다를 수 있다.

## 3. 요약

- OCR/멀티모달 추출 필수: 7페이지
- 선택 적용 권장: 1페이지
- OCR 불필요: 2페이지

## 4. 처리 권장안

1. 표 형태 스캔 문서는 300 DPI 수준으로 렌더링한 뒤 한국어와 영어 OCR을 함께 적용한다.
2. 시스템 구성도는 OCR 텍스트만으로 연결 관계가 손실될 수 있으므로 이미지 설명을 함께 생성한다.
3. OCR 결과는 원문과 구분해 `ocr_applied`, `ocr_engine`, `ocr_confidence` 메타데이터를 기록한다.
4. OCR 결과를 사람이 페이지 이미지와 대조한 뒤에만 Golden set의 정답 근거로 사용한다.
5. 빈 페이지와 미작성 서식은 검색 인덱스에서 제외하되 원본 페이지 기록은 유지한다.

## 5. 구현 상태

- 2026-07-21 기준 필수 7페이지에 한국어+영어 Tesseract OCR을 적용했다.
- OCR 결과는 `data/processed/ocr_pages.jsonl`에 저장했다.
- ingestion 재실행으로 페이지 메타데이터와 OCR 검색 청크 8개에 반영했다.
- 시스템 구성도 2페이지는 `multimodal_review_required=true`로 유지했다.
- `하_2` 10페이지 조직도는 선택 대상이므로 아직 OCR 검색 청크에 포함하지 않았다.
